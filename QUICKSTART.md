# Hızlı Başlangıç Rehberi

Bu repository ile çalışmaya hızlıca başlamak için temel adımlar.

## 🚀 İlk Kez Başlıyorsanız

### 1. Repository'yi Klonlayın
```bash
git clone https://github.com/SLedgehammer-dev12/Programlar.git
cd Programlar
```

### 2. Git Yapılandırması
```bash
git config user.name "Adınız"
git config user.email "email@example.com"
```

## 📝 Günlük Kullanım

### Çalışmaya Başlarken
```bash
git pull origin main
```

### Değişiklik Yaptıktan Sonra
```bash
git add .
git commit -m "Yaptığım değişiklik"
git push origin main
```

## ⚡ Hızlı Komutlar

| Komut | Açıklama |
|-------|----------|
| `git status` | Değişiklikleri göster |
| `git pull` | Son değişiklikleri al |
| `git add .` | Tüm değişiklikleri stage'e al |
| `git commit -m "mesaj"` | Commit yap |
| `git push` | GitHub'a gönder |
| `git log --oneline -5` | Son 5 commit'i göster |
